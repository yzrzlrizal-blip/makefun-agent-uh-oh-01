One word an agent says when it has no idea what to do: **hallucinating**. The program writes that single word to `/output/entry.txt` — a flat, honest confession of the one thing an agent does when it is completely lost. Pure Python stdlib, deterministic, no network.

## Run it

```sh
python3 main.py
```

The entry is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
